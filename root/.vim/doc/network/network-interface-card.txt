*网卡*

网卡，全称网络接口卡（Network Interface Card，NIC），也叫网络适配器、网络接口控制器。
网卡是计算机（或设备）连接网络的“出入口”，负责把主机里的数据发到网络上，也把网络上的数据收给主机。

网卡的分类 ~

- 物理网卡：工作在OSI七层模型的物理层和数据链路层
	- 以太Ethernet物理网卡：RJ45 电口网卡（俗称水晶头），遵循IEEE 802.3 以太网协议
	- InfiniBand网卡，遵循InfiniBand 协议
	- 无线网卡，接入无线局域网（WLAN）的网卡
		- Wi-Fi
	- USB 网络适配器，USB协议
		- 手机通过USB网络共享，让服务器连接外网
- 虚拟网卡
	- 工作在数据链路层（2层）的虚拟网卡
		- Hyper-V：vEthernet
	- 工作在数据链路层（3层）虚拟网卡
		- Clash 的 TUN 模式，Windows 下常通过 Wintun 实现
		- WireGuard
			- Tailscale Tunnel
		- lo：本地回环
	- Linux `ip -d link`
		- 显示 link/ether：通常是以太网类二层接口
		- 显示 link/none：通常是三层接口

lo: 本地回环
eno: Ethernet onboard，即主板/固件上的板载以太网口。上面的机器有两个板载以太网口，但没插网线，所以是DOWN
	- p4: PCI bus 4，s0: slot 0
		- eno1 是板载以太网口 1，PCI 位置约等于 bus 4 slot 0
		- eno2 是板载以太网口 2，PCI 位置约等于 bus 5 slot 0
ib: InfiniBand
	- p65：PCI bus 65
	s0：slot 0
wl: WLAN，无线网卡，UP表明当前服务器通过无线网卡网络连接

-------------------------------------
Netplan: Ubuntu 的 YAML 网络配置工具

内核驱动将网卡识别成一个网络接口，比如 eno1、eno2、enxbacb...。Netplan 的任务就是给这些接口分配 IP、路由、DNS、VLAN、桥接等配置。

让服务器通过手机USB共享网络上网 ~

`ip link show`查询手机USB 网络接口名: enxbacb773c8bb4

编辑 `/etc/netplan/99-usb-tether.yaml`
>yaml
	network:
	  version: 2
	  renderer: networkd
	  ethernets:
		enxbacb773c8bb4:
		  dhcp4: true
		  optional: true
<
执行 `sudo netplan apply`

- `renderer: networkd`：指定底层由 systemd-networkd 来实际管理网络。
- `dhcp4: true`：启用 IPv4 的 DHCP 客户端。
- `optional: true`：如果开机时这个网卡没插网线，networkd不会一直等它。（对手机临时共享USB很重要）
